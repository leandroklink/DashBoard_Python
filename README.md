# 📈 Dashboard de Faturamento - SuperMarket

Este projeto é um **dashboard interativo** desenvolvido com [Streamlit](https://streamlit.io/) e [Plotly](https://plotly.com/python/) para análise de faturamento de um supermercado.

## Funcionalidades
- Filtro por mês
- Gráficos interativos com Plotly:
  - Faturamento diário
  - Faturamento por tipo de produto
  - Faturamento por filial
  - Faturamento por tipo de pagamento
  - Avaliações
  - Evolução do faturamento mês a mês

## Tecnologias
- **Python**
- **Streamlit**
- **Pandas**
- **Plotly Express**
